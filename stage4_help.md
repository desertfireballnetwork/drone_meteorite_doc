## Introduction
Stage 4 is the in situ visit of meteorite candidates that remain after the remote sensing assessments.
To facilitate this, a GPS-enabled slippy map is used.
The map has background satellite imagery, with drone survey images overlaid on top, and an interactive layer for the meteorite candidates.





## Accessories list
- [ ] Android mobile device (1 pp). Need good gyro and compass. Cheap devices (<$500) are usually not suitable for this task (Samsung: S series devices are okay, but not the A series). Most people prefer a tablet over a phone for this task. The device needs a fair bit of free internal storage to cache candidates (rule of thumb: each cached candidate uses ~40MB), so make sure your devices has at least as couple of GB of free space.
- [ ] Power bank + charging cable.
- [ ] Personal Locator Beacon (1 pp).
- [ ] Hand-held UHF radio (1 pp) + charger.
- [ ] Garmin GPS unit (1 pp).
- [ ] AA batteries.
- [ ] Water, clothing, first aid kit etc. as appropriate for the site and conditions.



## What to do

### Set up

_Note: Android trusts apps from the Google Play Store by default and warns about apps from anywhere else,
so you may have to update some settings along the way to install the app (or even just to download it)._

- [ ] Download the stage 4 app on the tablet, using the latest `dfn-stage4-<tag>.apk` file from: [github.com/desertfireballnetwork/dfn-meteorite-drone-android-app](https://github.com/desertfireballnetwork/dfn-meteorite-drone-android-app/releases)
- [ ] Install it. Note: if you have a previous version installed, installing the new one should just replace the old one.
- [ ] Log in, using same credentials as web version.


### Before heading out, while you have good internet
- [ ] Go to the Basecamp tab <i class="fa-solid fa-house"></i>
- [ ] Claim a batch of candidates you want to visit (do not exceed 100). Clicking on them individually, or draw a polygon <i class="fa-solid fa-draw-polygon"></i> around an area and "Claim inside".
- [ ] Hit the download button <i class="fa-solid fa-download"></i>.
- [ ] The <i class="fa-solid fa-map"></i> Map should now have everything you need.
- [ ] Make sure you have all the safety equipment from the [Accessories list](#accessories-list).
- [ ] Do not rely on the app for returning to camp. Set a home point on GPS unit (+ on your phone as backup).
- [ ] Let someone know which general direction you are heading towards, and when you are expecting to return. For a small team (≤3) verbal is fine. For larger teams, use some sort of written system (whiteboard for example).


### While out
- [ ] Check in with others regularly using UHF.
- [ ] Revise planned loop if it is taking longer than expected.
- [ ] Visit candidates. Record if it is a meteorite (+optionally take a picture).
- [ ] Find a very convincing candidate? Follow the [procedure](meteorite_curation.html). Radio your location so other team members can come and find you.



### Coming back to camp
- [ ] Charge devices.
- [ ] Synchronise your results (<i class="fa-solid fa-arrows-rotate"></i> tab).
- [ ] Release the candidates you are no longer planning to visit in <i class="fa-solid fa-house"></i> Basecamp tab.
- [ ] (optional) Clear the cache in the <i class="fa-solid fa-gear"></i> Settings, to free up space on the device.
- [ ] Check up on others.
- [ ] Rest.

_Note: if an inconsiderate user has claimed candidates that they are not actually visiting, you can ask a survey core member to release claims from this person on the web version_





### If using the web browser version
The web version of stage 4 has more or less the same functionalities as the mobile app, except that it is browser-based.
This means that it cannot cache the data very well.
Use only if you can maintain an internet connection.
