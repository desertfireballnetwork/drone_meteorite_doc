# Drone Meteorite Searching Documentation

Documentation, tips, and checklists for finding meteorites with a drone. Published as a Jekyll site
(theme: [`just-the-docs`](https://github.com/just-the-docs/just-the-docs)) at
https://desertfireballnetwork.github.io/drone_meteorite_doc/.

This is linked to the [Drone Meteorite Searching Webapp](https://find.gfo.rocks/).

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then browse to http://localhost:4000/drone_meteorite_doc/.

Restart the server after editing `_config.yml` — Jekyll's watcher doesn't pick up config changes on its own.
